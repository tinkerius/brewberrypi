# BrewberryPi brand

<img src="logo.svg" alt="BrewberryPi" height="72">

The logo is a mash kettle in berry colour: a lid with a leaf for the knob, berry dots on the body,
a dial thermometer, a ball valve and three flames underneath. The name is set in Zilla Slab Bold.

All files are generated by `tools/build_brand.py`. Change the script and rebuild; don't edit the files by hand.

## Files

| File | Use |
|---|---|
| `logo.svg` / `logo-dark.svg` | Mark and name side by side, for light / dark backgrounds. The default logo. |
| `logo-stacked.svg` / `logo-stacked-dark.svg` | Mark above the name, for square spaces. |
| `logo-mono.svg` | Side-by-side logo in one colour (ink), for print, stamps and engraving. |
| `mark.svg` / `mark-dark.svg` | Mark only, 32 px and larger. `mark-512.png` is the same as a PNG. |
| `mark-small.svg` / `mark-small-dark.svg` | Simplified mark for 24 px and smaller: no berry dots, bigger dial, plain valve, bolder flames. |
| `mark-mono.svg` | Mark only in one colour. |
| `mark-reversed.svg`, `avatar.png` | Light mark on a berry square: GitHub avatars, profile pictures. |
| `favicon.svg`, `favicon.ico` | Browser tab icon (small mark). The SVG switches to the dark colours in dark mode. The ICO holds 16, 32 and 48 px. |
| `app-icon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Home-screen and web-app-manifest icons (mark on paper). |
| `social-preview.svg`, `social-preview.png` | GitHub social preview, 1280 × 640 (repository Settings → Social preview). |

HTML for a page `<head>`:

```html
<link rel="icon" href="favicon.ico" sizes="48x48">
<link rel="icon" href="favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="apple-touch-icon.png">
```

## Colours

Each colour has a darker value for light backgrounds and a lighter one for dark backgrounds.

| Colour | Used for | On light | On dark |
|---|---|---|---|
| Berry | kettle body, lid, handles, the "Pi" of the name | `#8a2a4a` | `#e0789a` |
| Leaf | knob | `#3d7a3c` | `#8fc77f` |
| Brass | dial, valve, flames | `#c4821a` | `#e9b04f` |
| Ink | the "Brewberry" of the name, one-colour versions | `#2a1d22` | `#f1e8eb` |
| Paper | backgrounds | `#fbf8f6` | `#1c1719` |

The reversed version (on berry `#8a2a4a`) uses paper `#fbf8f6` for the kettle, `#9fd18f` for the leaf
and `#f0bd5c` for brass.

## Typeface

[Zilla Slab](https://fonts.google.com/specimen/Zilla+Slab) Bold for the name, Medium for taglines.
It is licensed under the SIL Open Font License. In the SVG files the text is converted to outlines,
so the files show correctly without the font installed.

## Rules

- **Sizes:** use `mark.svg` from 32 px up and `mark-small.svg` below that. Don't use the logo smaller than 16 px.
- **Clear space:** keep free space around the logo of at least one eighth of the mark's height (about the height of the leaf knob).
- **Don't** stretch, rotate or outline the logo, change its colours other than with the files above,
  or place the colour version on a busy photo (use the one-colour or reversed version there).
- **Don't** combine it with the Raspberry Pi logo. It is a trademark of Raspberry Pi Ltd, and the
  BrewberryPi berry is deliberately our own drawing.

## Case emboss

The dots, dial gap and needle are cut out with SVG masks. OpenSCAD's SVG import ignores masks, so embossing
the logo on the printed case needs a flattened outline version. That gets made as part of a case spec
revision (`tinkerius/brewberrypi-case`), using `mark-mono.svg` as the source.

## Rebuilding

Needs Python with `fonttools`, `uharfbuzz`, `brotli` and `pillow`, and Node with `playwright` (for the PNG and ICO files).
The font is downloaded into `tools/.cache/` on the first run.

The build also copies the files the website uses into `site/` (stacked logos, marks, favicons, touch icon, social
preview) and writes Latin subsets of Zilla Slab Medium and Bold to `site/fonts/`, so the site never goes out of step
with the brand. Commit those changes together with the brand files.

```sh
pip install fonttools uharfbuzz brotli pillow
python3 brand/tools/build_brand.py
```
